# Native Titan Routes

```powershell
.\verify.ps1 -Scope Native -Suite TitanGold
```

Run from the repository root. Set `NGU_IDLE_DIR` or pass `-GameFolder` for the
installed game references. TitanGold is part of the public Native scope; its old
per-suite wrapper is removed. One incremental MSBuild invocation builds production
and selected fixture dependencies, then separate programs execute under shared
verification ownership. Do not race it with source edits, direct builds or EXEs.
Reports retain JSON/phase logs and artifact identity; contention/defer/drift exits 2
and appends `artifacts/agent-handoff.md`. A suite pass is not the all-scopes gate,
deployment or live acceptance. See [Testing And Save Safety](../../docs/testing.md).

The executable loads a fresh compiled production assembly and the installed game's
managed code offline. Native eligibility, native equipment getters, real pure
selection, Main.Execution claims/grants and selected actuation are not replaced.
The only injector rewrite is the existing managed Unity settings-JSON boundary.
Runtime artifacts are isolated under TEMP/opencode and removed on exit. No live
process, bridge, saves, deployment or installed assembly is touched.

## Contract

Temporary equipment is not a historical return target. Exit installs an actual
CURRENT baseline B if one is published and authorized; without one, native gear is
preserved while real claim authority retires. Every positive baseline has captured
model/settings/epoch/material continuity, not a synthetic HasSuccessor flag.
Selection is pure: impossible or unsupported candidates perform zero trial swaps.
Verified model state after a presentation exception is retained; genuine bounded
partial/unknown outcomes cannot admit dependent combat or trigger original rollback.
